Each mode needs a named configuration, documented guarantees, focused failure tests and separate benchmark results. Qualify the default profile and each optional profile independently.

| G1 Buffered finish | Bound pending finishes by count, bytes and age. Keep storage permits and lease handling through durable settlement. Test pressure, graceful drain and crashes that can rerun unsettled work. |
| G2 Reduced replay protection | **Upper-bound probe done 2026-11-15, not built.** With the receipt partitions unlogged (`--pg-no-receipts`), PostgreSQL drain of 10,000 jobs moved from 38.9 to 63.4 jobs/s (medians of 3 pairs, but per-pair ratios 1.21, 1.63 and 0.44) and WAL fell only 8% to 12% (112 to 124 MB against 122 to 140 MB). Closed as deferred; repeat on a quiet host only if the receipt share matters. Raw results: `artifacts/perf/round-two/pg-g2-receipts/`. Original text: Specify a shorter replay horizon and preserve historical finish identity within it. Test lost replies inside and outside the horizon, terminal jobs, retry/rerun and cleanup. Document when resending can create another job. |
