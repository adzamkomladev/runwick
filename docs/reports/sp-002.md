Date: 2026-10-30. Tag: `sp-002`.

## Delivered

- `global.json` pins SDK 10.0.403 (`rollForward: disable`); `eng/install-sdk.sh` installs it to `$HOME/.dotnet`.
- `Runwick.slnx` with 12 projects: `src/` (Runwick.Contracts, Runwick, Runwick.Postgres, Runwick.Testing), `tests/` (ReferenceModel, Harness, Harness.Peer, Core.Tests, Postgres.Tests, Workloads), `samples/` (Samples.Contracts, Samples.Host).
- Central package management with transitive pinning, lock files for every project, `TreatWarningsAsErrors`, latest-recommended analyzers, `CA2007`/`CA1849`/`CA2016` as errors.
- `eng/package-graph.json` plus `eng/check-package-graph.sh`: allowed edges, undeclared projects, cycles, and the producer budget (Samples.Contracts may depend on no package other than Runwick ones).
- CI workflow `.github/workflows/ci.yml`: locked restore, Release build, graph check, vector verify, Core.Tests and Postgres.Tests, pack. A nightly matrix runs postgres:16/17/18.
- Public API surface from spec 01 compiles:
  - Contracts: job, handler, attributes, identities, context, middleware, results, dispatch records, `IJobDispatcher`.
  - Core: builders, layered policy resolution, a registry compiler that collects every error into one `RunwickConfigurationException`, `IRunwickJobRegistry` with its source map, exception hierarchy, `RunwickErrorCodes`, `PreparedDispatch`/`PreparedBatch`/`DispatchResolution`/`IPreparedJobDispatcher` with export/import codec, `AddRunwick`.
  - PostgreSQL: `UsePostgres`, `PostgresOptions`.
- The internal storage protocol from spec 03 §2–§3 compiles as internal records and interfaces.
- The sample host compiles a registration that mixes attribute-declared (`SendWelcomeEmail` with a v1→v2 upgrade) and fluent-only (`BuildReport`) contracts.
