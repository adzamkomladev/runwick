# SP-007 acceptance report: Reserve

Date: 2026-10-30. Tag: `sp-007`.

## Delivered

- Reserve/1 (04 §7.3) was implemented in SP-005 (`PgStore.Reserve.cs`):
  - queue control `FOR SHARE` with the pause check;
  - one `SKIP LOCKED` candidate in `(eligible_at, job_id)` order, filtered by the advertised decoding tuples;
  - generation read, then scope rows locked in UUID order;
  - fresh decision time;
  - live permit count, giving `CapacityBlocked` with `BlockedScopeId` and `ResumeAfter`;
  - fences, attempt, job update, permits, event and payload;
  - receipt replay re-reads the payload.

  SP-007 adds the contract and fault tests below. No production code changed for SP-007.
- Test contracts `test.capped` and `test.pair` and the peer `conflicts` command were committed with SP-006.

## Notes

- ADM-05's "at most 8 blocked candidates" is the engine's lane-visit budget (05 §4, 03 §7). The store's Reserve/1 inspects one candidate per command. The test drives the visit loop as the engine will in SP-009, and the 8-blocked budget is enforced there.
