## Spec changes (dated 2026-10-31)

13 is a new document; it replaces 01 §18 "reserved" and 03 §8.4. It resolves C-1 … C-11 (13 "Changes"). The main ones:

- schedule operations have their own lifetime family (C-1);
- eight operations, with no Delete in M3 (C-2);
- one 2 MiB ceiling (C-3);
- no scheduler lease (C-4);
- a dedicated `schedule` scope kind (C-5);
- audit and events per operation (C-6);
- the lock rank (C-11).

The cross-document edits E-1 … E-11 from `docs/plans/sp-016-shared-edits.md` were applied to 00, 01, 03, 04, 05, 06 (§1.14) and 08.

## Fixes found while testing

- The namespace `Runwick.Dispatch` was wrong in `ScheduleBuilder`, `SchedulerService` and `ScheduleStoreTests`; it is `Runwick.Dispatching`. It did not compile before.
- `RunwickServiceCollectionExtensions` now qualifies the `Runwick.Management` types with `global::`, which resolves a name clash in the DI registrations.
- `PrepareItem` became internal so the store can build template jobs. `DispatchCoreAsync` takes `createdReason`.
