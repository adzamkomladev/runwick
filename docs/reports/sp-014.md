## Spec changes (dated 2026-10-31)

11 is a new document; it lifts the M2 refusal of `AutoConcurrency`. Contradictions resolved (11 "Changes"): demand is shared without a coordinator (C-1); min 0 starts with one bootstrap ticket (C-2); the boundary waiver (C-3); overrides apply per worker incarnation and pool (C-4); unknown demand is never read as zero (C-5). 06 gains §1.13, the scaler constants, and rewords V-15. 00, 01, 03, 04 and 05 carry matching Changes entries.

## Fixes found while testing

- `ScalingTests` override replay (test only): the replay sent a different NotAfter, so it was correctly a `CommandConflict`. It now reuses the same NotAfter, floored to milliseconds.
- `WorkerHost` (harness): `FixedConcurrency` is now set only when `concurrency > 0`, so a test can configure `AutoConcurrency` itself.
- `CapacityCaseTests.Pool_bounds_and_group_limits_are_validated_at_startup` (added by SP-010 on main): it expected the M2 `feature_not_available` refusal. It now expects `AutoConcurrency(5, 3)` to fail V-15 as `invalid_pool`, and `AutoConcurrency(1, 17)` to fail as `pool_budget_exceeded`.
- `OccupancyIntegrator.Mean`: `ArgumentOutOfRangeException.ThrowIfLessThanOrEqual` (CA1512).
