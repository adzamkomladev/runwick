### Mac (or Linux with the WebKit libraries): DASH-07 WebKit smoke

Needs: the .NET SDK `10.0.403`, Node 18 or newer, and a PostgreSQL 16, 17 or 18 you can reach (Docker is easiest). On Linux the WebKit system libraries are also needed; that is what this machine lacks.

1. Install the browser tool and its WebKit:
   ```
   npm i -g @playwright/cli@0.1.22
   playwright-cli install-browser webkit
   ```
   (Linux only, if WebKit then fails with "Host system is missing dependencies": `sudo npx playwright install-deps webkit`.)
2. Start a scratch PostgreSQL (skip if you have one):
   ```
   docker run -d --name runwick-pg-webkit -e POSTGRES_PASSWORD=pg -p 55499:5432 postgres:18
   ```
3. Build the sample host and run the WebKit smoke flow, from the repo root:
   ```
   dotnet build samples/Runwick.Dashboard.Host
   RUNWICK_DASH_PG='Host=127.0.0.1;Port=55499;Username=postgres;Password=pg;Database=postgres' \
     src/Runwick.Dashboard/ClientApp/e2e/browser.sh webkit
   ```
   Pass: every printed line starts with `pass` and the script exits 0. A line starting `FAIL  webkit: did not launch` means the browser or its libraries are missing, not a dashboard failure.
4. Remove the container afterwards: `docker rm -f runwick-pg-webkit`.

When it passes, the DASH-07 PostgreSQL cell in `docs/conformance/cases.csv` can change from `partial: ...` to `applicable`, and SP-024's "WebKit not run" line can be closed.
