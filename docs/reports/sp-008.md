# SP-008 acceptance report: Begin, Renew, Finish, Recover, ReleaseReservation

Date: 2026-10-30. Tag: `sp-008`.

## Delivered

- The ownership operations (04 §7.4–§7.8) were implemented in SP-005. SP-008 adds the contract and fault tests below and the fixes they found.
- **Renew permit check (OWN-05, spec change P-27).** Renew/1 now requires every permit's expiry to equal the job's current lease expiry (`AND lease_expires_at = @previous`). Before this, a permit row with a stale expiry was renewed silently. A mismatch is now `InvariantFault` `permit_set_mismatch`, with no change to any row. Recorded in 04-postgres.md as P-27, dated 2026-10-30.
- **`ReservedJob.CreatedAt`.** The Reserve payload read now joins `jobs` and returns the job's creation time. `IJobContext` (SP-009) needs it. This is an additive field; the receipt replay path reads the same value.

## Fixes made while testing

- RUN-01 used a 1.5 s peer lease and so hit `StaleLease` on Begin under load. It now uses the 3 s lease from the spec, follows the reserved lease's `JobId`, and its recovery wait is bounded.
- OWN-01's 1.5 s lease with a 400 ms margin was too tight for a loaded host. It now uses a 4 s lease and starts the race 1.5 s before expiry; the race itself is unchanged.
- TIME-05 dispatches every job up front and maps replies by `JobId`. Before, a retried job with a 1 ms delay could be reserved ahead of a newly dispatched one.
