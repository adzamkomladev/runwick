# SP-003 acceptance report: test harness

Date: 2026-10-30. Tag: `sp-003`.

## Delivered (tests/Runwick.Harness, tests/Runwick.Harness.Peer)

| Spec 07 | Component | Notes |
|---|---|---|
| §2.1 | `DriverFixture` | Provides `StartAsync(ns, profile)`, `OpenClient("local")`, `OpenPeer(identity)`, `ReadCommittedSnapshot`, `ArmFault`, `WaitAtBarrier` / `ReleaseBarrier`, `RestartStore` (which re-points the proxy), `SetQueuePaused` (the internal SetQueueState/1), `PruneReceipts` (the 04 §7.16 predicate), `StoreNow` and `Proxy`. Supports the profiles `DirectPrimary` and `DirectPrimaryViaProxy`. |
| §2.1 | `TestClient` | The real `AddRunwick(...).UsePostgres(...)` service graph: registry, dispatcher, PostgreSQL store and SQL. It adds typed helpers for Reserve, Begin, Renew, Finish, Recover and Release, and records a per-call history (command ID, operation, status, effect, replayed flag, decision time, monotonic send and receive). |
| §2.2 | `SnapshotReader` | One REPEATABLE READ READ ONLY transaction over the 13 tables. Rows are normalized: payloads become length + SHA-256, instants become ms. It returns the reference-model `StoreSnapshot` and `DiffTables`. |
| §2.3 | `HarnessFaultInjector` | Fault points and targets as in spec 07: Throw (Transient / Io / Deadlock40P01 / Serialization40001), Delay, Barrier and DropReply, targeted by command, operation, application, step and occurrence, with a `times` count. Throw at `AfterCommitBeforeReply`, DropReply anywhere else, and KillProcess on `local` are all rejected. |
| §2.4 | `PeerClient` + `Runwick.Harness.Peer` | A separate OS process speaking JSON Lines. Commands: `open`, `dispatch`, `reserve`, `begin`, `renew`, `finish`, `recover`, `release`, `armFault` (including `KillProcess`) and `releaseBarrier`. Events: `atBarrier` and `reply`. The fixture uses SIGKILL for the whole process tree. `startWorker` / `stopWorker` reply "needs SP-009" until the engine lands. |
| §2.5 | `PgFaultProxy` (WireProxy) | Pass-through, `SetLatency(delay, direction, roleFilter)`, `ArmCommitReplyDrop(times, roleFilter)` (records the CommandComplete tag `COMMIT`/`ROLLBACK`), `Sever(roleFilter)` and `Retarget`. Connections are tagged `rw:<identity>:control|work` (spec 04 P-24). |
| §2.6 | `StoreServer` / `TestDatabase` | Testcontainers `postgres:18` with fsync, synchronous_commit and full_page_writes on, one per assembly. `rw_template` is migrated once. Each test runs `CREATE DATABASE rw_<ns> TEMPLATE rw_template` and gets a fresh store ID. The `RUNWICK_TEST_PG` escape hatch is supported. |
| §2.7 | `TestTiming.Fast` | Every worker default ÷ 10. |

## Self-tests (`Item=SP-003`, Postgres.Tests)

| Case | Proves | Result |
|---|---|---|
| HARNESS-barrier | A barrier holds Reserve after its locks. A second claimant skips the locked row. Release completes the held Reserve. | passed |
| HARNESS-throw | Throw rolls back to the exact pre-state and is classified not-applied. Deadlock-kind faults are retried with the same identity (two fired, then applied). | passed |
| HARNESS-proxy | The proxy drops the COMMIT reply, recording tag `COMMIT`. The client gets outcome-unknown. Replaying the same command gives `Replayed`, with exactly one attempt. | passed |
| HARNESS-proxy-latency | Latency applies only to the `control` role. Sever kills the control connections; the next call fails known-not-applied and the following one reconnects. | passed |
| HARNESS-peer | The peer dispatches and reserves. KillProcess at Begin/BeforeCommit reports `atBarrier`, and SIGKILL leaves the job reserved with 0 starts and the invariants intact. | passed |
| HARNESS-snapshot | Snapshots are stable and payloads redacted. | passed |
| HARNESS-model | The reference model accepts Reserve → Begin → Finish and rejects Begin-without-Reserve. | passed |
| HARNESS-controls | SetQueuePaused gives `QueuePaused` and resume claims again. PruneReceipts honours `retain_until`. StoreNow is monotonic. | passed |
| HARNESS-restart (`RequiresDocker`) | `RestartStore(Kill)` keeps the data and clients reconnect. | passed (it is skipped under the escape hatch) |
| HARNESS-timing | The Fast profile values and the 3.1 s < 5 s renewal margin. | passed |

The full Postgres.Tests suite (SP-003 + SP-005) ran on Testcontainers `postgres:18`: 28 passed, 0 failed, 0 skipped.
