## Spec changes (dated 2026-10-30)

- **05 §17, health.** The `Runwick` package graph does not allow `Microsoft.Extensions.Diagnostics.HealthChecks`. Health is therefore the internal snapshot `WorkerEngine.Health()`, and a HealthChecks adapter is deferred to a package that may reference it (M5).
- **07 §2.7, real-store test timing.** Real-store worker tests use `TestTiming.Scaled(RUNWICK_TEST_TIMING_DIVISOR)`, default ÷4, instead of Fast (÷10). On this shared host (load average ≈ 15 on 8 vCPU) store calls stalled for seconds at a time. Fast's 500 ms request timeout and 1.5 s Begin budget then expired, as designed: BeginUnresolved and SafetyDeadline losses, followed by recovery, never a double invocation. That made steady-state assertions nondeterministic. Pure tests use fake time with the default timing.

## Fixes found while testing

- `PriorityGate`: cancellation registrations on long-lived stop tokens were never disposed. They are now disposed when the wait ends.
- `AttemptEntry` owns a `CancellationTokenSource`. It is disposed at retirement, and its token is captured at construction so it stays readable afterwards.
- WRK-18 (test only): the first Testcontainers run failed waiting for the unbegun claim. The finishing job's held Finish tripped the pressure gate (oldest Finish ≥ 5 s stops new Reserves, 05 §15), and the loaded host took longer than 5 s to reach the third Reserve. That is correct engine behaviour. The finishing job's handler is now held by the peer (`hold` prefix, `releaseHeld` command) until the unbegun claim exists, so the order no longer depends on host speed.

## Test harness added

- `EngineFixture` (Harness, 07 §2.8): the real engine over `FakeTimeProvider` and `ScriptedStore`. The store is an in-memory `IRunwickStore` with receipts by command ID and per-call script hooks: `Before` (proceed, fail, hang), `Rewrite` and `DropReply`.
- `WorkerHost` (Harness): the real `AddRunwick(...).UsePostgres(...).AddWorker(...)` host, using `HandlerScript` and `WorkJob`.
- The peer process supports `startWorker` and `stopWorker` (07 §2.4).
